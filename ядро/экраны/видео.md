# Экран «видео» — живая запись вместо описания

## Зачем

Там, где описание уже не убеждает, убеждает запись: короткое обращение, съёмка «как всё проходит»,
кадры с места. Человек видит и слышит того, к кому собирается прийти.

## Обязательно

- Окно с роликом 16 : 9 слева, шапка и список «что увидите» справа; на телефоне ролик идёт первым
  — сперва кадр, потом слова о нём (`.видео__плеер`, `.видео__текст`, `.видео__список`).
- Окно держит три формы, и смешивать их нельзя — плеер на экране один: адрес плеера у площадки с
  видео; свой файл из `video/` с кадром-постером; ролика ещё нет — заглушка в том же окне и 🟡.
- Свой файл не стартует сам: кнопку жмёт человек, и звук приходит с его нажатием. Приглушать
  (`muted`) ролик можно только вместе с автозапуском — на этом экране автозапуска нет вовсе.
- Строка длительности со значком часов: человек решает, есть ли у него эти четыре минуты, до того
  как нажмёт кнопку.
- Пунктов «что увидите» 3–5. Они не пересказывают ролик, а называют, ради чего его смотреть.
- Экран без строки `Видео` в прототипе не собирается вовсе.

## Доказательство

Самим роликом: он и есть довод. Подпись под окном говорит, что это за запись и когда снята
(«Запись открытого занятия, март 2026»), — без даты запись читается как рекламный кадр.

## Поля прототипа

| Поле | Куда встаёт |
|---|---|
| `Видео` | адрес плеера `{{ВИДЕО_АДРЕС}}` либо свой файл `{{ВИДЕО}}` с кадром `{{ПОСТЕР}}`; `нет` — заглушка в окне. Поле обязательное: без него экрана нет |
| `Подпись видео` | подпись под окном, `{{ПОДПИСЬ_ВИДЕО}}`; нет — подписи нет |
| `Длительность` | строка со значком часов, `{{ДЛИТЕЛЬНОСТЬ}}`; нет — строка стирается целиком |
| `Кикер` | строка над заголовком, `{{КИКЕР}}` |
| `Заголовок` | заголовок секции, `{{ЗАГОЛОВОК}}` |
| `Подзаголовок` | лид шапки, `{{ПОДЗАГОЛОВОК}}` |
| `Список` | «что увидите»: `{{ПУНКТ_1}}` `{{ПУНКТ_2}}` `{{ПУНКТ_3}}` и пояснения после первого тире — `{{ПОЯСНЕНИЕ_1}}` `{{ПОЯСНЕНИЕ_2}}` `{{ПОЯСНЕНИЕ_3}}` |

## Роль в ритме

`ключ--глубже`, громкость средняя. Место одно: после работ или кейса, перед отзывами — сперва
человек видит, что сделано, потом смотрит, как это выглядит вживую, и только потом слушает чужие
слова. На длинной странице это обязательный шаг, на визитке — по желанию.

## Компоновки

- Окно слева, список «что увидите» справа, длительность под ним: `ядро/галерея/примеры/видео/`
- Ролик в чистой рамке во всю ширину, текст под ним двумя колонками
- Ролик в окне браузера с адресом в баре — когда показываешь работу на экране
- Окно на цветной плите (`.карточка--цвет`) с подписью-стикером: `ядро/галерея/примеры/страница-целиком/`

## Нельзя

- Чужая запись даже временно: экран про это дело, и подмену узнают по первому вопросу.
- Адрес без `https://` и площадка, которой никто не знает: по `http` браузер покажет пустое место.
- Автозапуск со звуком — разговор, который начался без спроса.
- Дорожка субтитров: её не бывает ни здесь, ни на обложке.
- Подменять этим экраном витрину работ: там роликов много и каждый мелкий, здесь один и крупно.
