# Экран «программа» — что внутри по неделям

## Зачем

Длинную программу нельзя вывалить списком: человек должен видеть, сколько в ней частей, и уметь
заглянуть в любую. Экран сворачивает её в аккордеон и показывает путь целиком.

## Обязательно

- Шапка секции: кикер, заголовок, лид, ряд итоговых цифр и строка-подсказка под ними.
- Части 1–4, внутри каждой модули; всего модулей 1–16, нумерация сквозная: вторая часть начинается
  с того номера, на котором кончилась первая (`.часть`, `.модуль`).
- Раскрывает модуль сам элемент раскрытия, без единой строки скрипта: у кого он выключен, тот всё
  равно откроет любой модуль.
- Открыт заранее только первый модуль первой части. Раскрыть ещё пару — и на телефоне страница
  вытянется на несколько метров, а человек так и не увидит, сколько в программе частей.
- Итоговые цифры в шапке — только те, что считаются по самому списку (частей, модулей, недель).
- Врезка-итог под аккордеоном: чем человек выходит в конце пути.

## Доказательство

Составом: срок у модуля, инструменты, с которыми работают, и строка «На руках» — что остаётся
после этого модуля. Программа, где у каждого модуля назван результат, убеждает сильнее любого
обещания в шапке.

## Поля прототипа

| Поле | Куда встаёт |
|---|---|
| `Кикер` | строка над заголовком, `{{КИКЕР}}` |
| `Заголовок` | заголовок секции, `{{ЗАГОЛОВОК}}` |
| `Подзаголовок` | лид шапки, `{{ПОДЗАГОЛОВОК}}` |
| `Доказательство` | ряд цифр `{{ЦИФРА_1}}` `{{ЦИФРА_2}}` `{{ЦИФРА_3}}` с подписями `{{ПОДПИСЬ_ЦИФРЫ_1}}` `{{ПОДПИСЬ_ЦИФРЫ_2}}` `{{ПОДПИСЬ_ЦИФРЫ_3}}`; чисел нет — ряд стирается |
| `Список` | часть — `{{ЧАСТЬ_1}}`, вложенные строки — модули: номер `{{НОМЕР_МОДУЛЯ_1}}` `{{НОМЕР_МОДУЛЯ_2}}`, имя `{{ШАГ_1}}` `{{ШАГ_2}}`, рассказ после первого тире `{{ОПИСАНИЕ_ШАГА_1}}` `{{ОПИСАНИЕ_ШАГА_2}}` |
| `· срок:` у пункта | первая метка в строке модуля: `{{СРОК_1}}` `{{СРОК_2}}` |
| `· метка:` у пункта | метка части `{{МЕТКА_ЧАСТИ_1}}` и вторая метка модуля `{{ТАРИФ_1}}` `{{ТАРИФ_2}}` |
| `· инструменты:` у пункта | тег «Работаем в: …» в теле модуля: `{{ИНСТРУМЕНТЫ_1}}` `{{ИНСТРУМЕНТЫ_2}}` |
| `· на руках:` у пункта | строка результата внизу модуля: `{{РЕЗУЛЬТАТ_1}}` `{{РЕЗУЛЬТАТ_2}}` |
| `После шагов` | врезка под аккордеоном: `{{ИТОГ}}` и `{{ПОЯСНЕНИЕ_ИТОГА}}` |

## Роль в ритме

`ключ--основной`, громкость средняя. Обычное место — после обещания и до цены: человек уже понял,
что получит, и хочет знать, из чего это собрано. Аккордеон — своя раскладка, поэтому он хорошо
стоит между сеткой карточек и разворотом.

## Компоновки

- Части с метками, внутри модули-аккордеон, врезка-итог под ними: `ядро/галерея/примеры/программа/`
- Один список модулей без деления на части — когда программа короткая
- Части плитками слева, модули выбранной части справа — когда частей четыре
- Номера модулей цветными плитами (`.плитка-цифры`, `.кромка--акцент`) в ленте по неделям:
  `ядро/галерея/примеры/страница-целиком/`

## Нельзя

- Подменять этим экраном `что-получите`: там результат на руках, здесь путь к нему.
- Раскрывать заранее больше одного модуля.
- Считать в шапке то, чего в списке нет: «120 часов практики» при десяти модулях без часов.
- Модуль без результата: название без «на руках» ничего не обещает.
- Прятать за аккордеон единственные три пункта — их проще показать списком.
